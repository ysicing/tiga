# Tiga 数据目录规范与安装向导说明

## 📂 目录结构规范

### 配置目录：`/etc/tiga/`

**用途**：仅存放配置文件

```
/etc/tiga/
├── config.yaml          # 主配置文件（最小配置 + 安装向导生成）
├── config.yaml.example  # 完整配置示例
├── .env.example         # 环境变量示例
└── agent.env            # Agent 环境变量（可选）
```

**权限**：
- 所有者：root:root
- 权限：644（可读）

**重要**：安装向导完成后，config.yaml 会包含：
- server 配置（install_lock, app_name, domain, ports, language）
- database 配置（type, database, host, port, username, password）
- security 配置（jwt_secret, encryption_key）

### 数据目录：`/var/lib/tiga/`

**用途**：存放所有应用数据

```
/var/lib/tiga/
├── tiga.db              # SQLite 数据库文件（如使用 SQLite）
└── recordings/          # 终端录制文件（运行时创建）
    ├── docker/          # Docker 容器终端录制
    ├── ssh/             # WebSSH 主机终端录制
    └── k8s/             # K8s 终端录制
        ├── node/        # 节点终端
        └── pod/         # Pod 容器终端
```

**权限**：
- 所有者：tiga:tiga
- 权限：755（tiga 用户可读写）

### 日志目录：`/var/log/tiga/`

**用途**：应用日志文件（如需文件日志）

```
/var/log/tiga/
├── tiga.log             # 主服务日志（可选）
└── tiga-agent.log       # Agent 日志（可选）
```

**权限**：
- 所有者：tiga:tiga
- 权限：755

**注意**：默认使用 systemd journal，此目录备用。

## 🎉 安装向导机制

### 软件包安装后的初始 config.yaml

```yaml
# Minimal configuration - Installation wizard will complete this

database:
  type: sqlite
  database: /var/lib/tiga/tiga.db  # ✅ 预设生产环境路径
```

**说明**：
- **不包含 `install_lock`**，首次访问会触发安装向导
- 只预设数据库路径，确保使用正确的生产环境目录
- 其他配置由安装向导生成

### 安装向导完成后的 config.yaml

```yaml
server:
  install_lock: true  # ✅ 安装向导完成后自动设置
  app_name: Tiga Dashboard
  domain: localhost
  http_port: 12306
  grpc_domain: localhost
  grpc_port: 12307
  language: zh-CN

database:
  type: sqlite
  database: /var/lib/tiga/tiga.db  # ✅ 保持生产环境路径

security:
  jwt_secret: <auto-generated-32-bytes>
  encryption_key: <auto-generated-32-bytes>
```

### 安装向导流程

1. **首次访问**：http://localhost:12306
2. **自动重定向**：/install（检测到 install_lock 不存在或为 false）
3. **步骤 1**：数据库配置
   - SQLite：已预设 /var/lib/tiga/tiga.db
   - PostgreSQL/MySQL：输入连接信息
4. **步骤 2**：管理员账户创建
5. **步骤 3**：系统设置
6. **自动完成**：
   - 初始化数据库表
   - 创建管理员用户
   - 生成安全密钥
   - 更新 config.yaml 设置 `install_lock: true`

## ⚙️ 配置路径规范

### ✅ 正确配置（生产环境）

```yaml
database:
  type: sqlite
  database: /var/lib/tiga/tiga.db  # ✅ 绝对路径，数据目录
```

### ❌ 错误配置

```yaml
# 错误 1：数据放到 /etc
database:
  database: /etc/tiga/tiga.db  # ❌ 违反 FHS 标准

# 错误 2：使用相对路径
database:
  database: tiga.db  # ❌ 依赖工作目录（开发可以，生产不行）
```

## 🔄 环境差异

### 开发环境（源码运行）

```yaml
database:
  type: sqlite
  database: tiga.db  # 当前目录（方便开发）
```

### 生产环境（系统包安装）

```yaml
database:
  type: sqlite
  database: /var/lib/tiga/tiga.db  # 绝对路径（符合 FHS）
```

**说明**：
- 开发环境使用相对路径方便快速测试
- 生产环境必须使用绝对路径确保可预测性
- systemd WorkingDirectory 设置为 /var/lib/tiga

## 📋 安装流程

### 软件包安装完整流程

1. **安装软件包**
   ```bash
   sudo apt install ./tiga_*.deb
   ```

2. **自动执行**（preinstall.sh）
   - 创建 tiga 用户和组
   - 创建目录：/var/lib/tiga, /var/log/tiga

3. **自动执行**（postinstall.sh）
   - 设置目录权限（tiga:tiga）
   - 重载 systemd
   - 显示安装向导使用说明

4. **启动服务**
   ```bash
   sudo systemctl start tiga
   ```

5. **访问安装向导**
   - 浏览器打开：http://localhost:12306
   - 自动重定向到 /install

6. **完成安装向导**
   - 选择数据库类型（默认 SQLite，路径已设置）
   - 创建管理员账户
   - 配置系统设置
   - 自动初始化完成

7. **启用开机自启**
   ```bash
   sudo systemctl enable tiga
   ```

## 🚨 常见问题

### Q1: 安装向导在哪里？

A: 首次启动服务后访问 http://localhost:12306 会自动重定向到安装向导。

### Q2: 能跳过安装向导吗？

A: 不能。必须完成安装向导才能使用系统。安装向导会：
- 初始化数据库
- 创建管理员账户
- 生成安全密钥

### Q3: 安装向导重复运行怎么办？

A: 安装向导只能运行一次。完成后 `install_lock: true` 会阻止再次访问。

### Q4: 如何重新运行安装向导？

A: 需要手动编辑配置文件：
```bash
sudo vi /etc/tiga/config.yaml
# 设置 install_lock: false 或删除该行
sudo systemctl restart tiga
```

⚠️ **警告**：重新运行会覆盖现有配置！

### Q5: SQLite 数据库文件在哪里？

A: `/var/lib/tiga/tiga.db`（安装向导完成后自动创建）

### Q6: 录制文件存在哪里？

A: `/var/lib/tiga/recordings/`（首次录制时自动创建）

## 🔍 验证安装

安装后运行验证脚本：

```bash
sudo bash /usr/share/doc/tiga/validate-install.sh
```

或手动验证：

```bash
# 检查目录
ls -ld /etc/tiga /var/lib/tiga /var/log/tiga

# 检查权限
stat /var/lib/tiga

# 检查服务状态
sudo systemctl status tiga

# 检查配置
cat /etc/tiga/config.yaml
```
